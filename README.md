# Amani Creative Canvas

Create a modern, minimal, friendly, and premium portfolio web app for Aidi (Amani Didier).

Here are the details and requirements:
- Identity: Name is Amani Didier (nickname: Aidi). Profile image is attached (the photo in the green turtleneck/jacket with headphones and glasses). The YouTube/brand avatar is also attached (the mascot chipmunk character labeled Aidi).
- Theme & Colors: Adaptive color theme toggle (dark/light) with a vibrant, playful palette incorporating black, white, minion yellow, electric blue, clean Duolingo green, and refined clothing grays.
- Style: Clean, minimal, tactile, and editorial with friendly touches. Include cool floating stickers and hand-drawn accents (stars, crowns, doodles) that give personality without looking cluttered or like a generic AI template.
- Projects Showcase: Showcase top projects from GitHub (https://github.com/amanididier) with custom cards, tags, live links, and GitHub repo links:
  1. Bob (Research Application) — AI-powered research assistant ("The friend that makes your research work easier", TypeScript)
  2. Urugendo — Modern web application (live at urugendo-v0.vercel.app, TypeScript)
  3. AI Agent Interview — Platform for practicing tech job interviews with technical and behavioral questions (TypeScript)
  4. Sanipads — Community and health web platform for sanitary pads accessibility (TypeScript)
  5. Hot Seat & Let's Build Together
- YouTube & Content: A section dedicated to the YouTube channel (@Aidi) showcasing videos and stories like "Can I build a billion dollar company in one month?", sharing tech experiments, vibe coding, and honest builder journey updates.
- Skills & Hobbies: Vibe coding, drawing logos & UI design, video editing in CapCut, 3D animation in Blender, tech exploration, and sharing laughs.
- Adventures & Passions: An interactive gallery/section celebrating life adventures: visiting the moon and Mars, flying in planes, visiting the Musanze mountain gorillas in Rwanda, running, singing, and a deep love for water/lakes/oceans.
- Contact & Socials: Direct links to GitHub (https://github.com/amanididier), YouTube, and a quick contact form/link.
